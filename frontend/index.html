Подробные условия участия

Правила партнёрской программы

  1. Партнёрская программа доступна всем зарегистрированным пользователям Creative Jam.
  2. Каждый пользователь получает уникальную реферальную ссылку.
  3. Бонусы начисляются после активации аккаунта приглашённого пользователя.
  4. Активация — это регистрация + создание первого проекта.
  5. Самоприглашения и мультиаккаунты не допускаются.
  6. Creative Jam оставляет за собой право изменять условия программы.
  7. Накопленные бонусы можно использовать для оплаты подписки и дополнительных генераций.
